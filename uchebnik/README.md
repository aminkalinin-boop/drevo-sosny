# Учебное пособие «Древо отраслей»

**Составитель:** Минигулов Александр Рафаильевич, 2026.

**Открыть онлайн:** https://aminkalinin-boop.github.io/drevo-sosny/uchebnik/

Это самостоятельное учебное пособие, расположенное внутри папки `uchebnik/`. Оно не подключено к основному интерфейсу приложения и не изменяет его поведение.

## Назначение

Книга сохраняет **27 тематических разделов** исходного справочника: по девять для лесопромышленного комплекса, агропромышленного комплекса и межотраслевого взаимодействия. Последовательность этапов: ресурсы; производство; переработка; техника; рынок; УИС; перспективы; идеальный цикл; регионы.

Внутри каждого раздела автоматически воспроизводятся названия, иерархическая нумерация, исходные пояснения, дочерние узлы, связанные понятия, соответствующие изображения и схемы. Дополнительные учебные лекции включают объяснения, производственные цепочки, учебные кейсы и вопросы для самопроверки.

В приложениях доступен каталог оборудования с иллюстрациями, а также терминологический словарь. Карточки, которые не входят непосредственно в 27 основных деревьев, сохраняются в дополнительном разделе, а не отбрасываются.

## Откуда берутся сведения

Для исключения расхождений книга **читает** существующие файлы справочника из родительской папки (`../`):

- `pine.js`, `pine2.js`, `species.js`, `schemes1.js`, `schemes2.js`, `uis.js` — лесопромышленный материал;
- `apk_*.js` — агропромышленный материал;
- `chains.js`, `cycles.js`, `flows.js`, `structure.js` — цепочки, циклы, иерархия;
- `tools.js`, `tech.js` — оборудование;
- `regions.js`, `photos.js`, `assets2.js` — `assets12.js` — карты и изображения;
- `enrich.js` — подробные дополнительные пояснения в исходном справочнике;
- `glossary.js`, `glossary2.js` — терминологические определения.

Изображения `.webp` и схемы `.svg` выводятся по уже существующим путям. Они не дублируются и не заменяются новыми изображениями.

## Как читать и печатать

1. Откройте `index.html` по адресу GitHub Pages, указанному выше. Для локального использования откройте весь репозиторий через локальный веб-сервер: при копировании только папки `uchebnik` отсутствуют исходные данные и рисунки.
2. В оглавлении выберите отрасль и главу. Содержание главы включает все уровни её дерева; в поиске можно находить конкретные карточки, термины и технику.
3. Кнопка «Печать раздела / PDF» вызывает печать браузера. Выберите «Сохранить как PDF» и формат A4.
4. Ссылка «Вся книга для PDF» открывает `?print=all`, где собраны все главы и приложения. Полный документ очень большой; для более надёжного экспорта лучше сохранять главы по отдельности.

## Методические замечания

- **Источник и дополнение разделены:** основное содержание карточек читается из приложения, а учебные лекции — из `theory.js`.
- Порядок дочерних узлов определяется исходным массивом `c`. Повторные переходы к одному узлу внутри главы сохраняются как связи и не превращаются в дублированные карточки.
- Числа и нормативные утверждения приложения могут устаревать; учебные тексты не заменяют актуальную проверку по правовым и статистическим источникам.
- Идеальные производственные циклы — аналитические модели, а не подтверждённые технико-экономические проекты. Их реализуемость требует расчётов.
- Контуры региональных карт взяты из имеющегося в приложении набора amCharts geodata. Лицензия находится в корне репозитория.
- Модель сборки не включает копирование изображений или создание нового содержания внутри исходных JavaScript-файлов.

## Гарантия изоляции

В рамках подготовки пособия новые файлы размещаются **только в папке `uchebnik/`**. `index.html` приложения, CSS и исходные модули данных на верхнем уровне репозитория не редактируются. При обновлении приложения пособие может показывать его обновлённые карточки, потому что подгружает данные непосредственно из него.
