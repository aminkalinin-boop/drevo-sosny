# Древо сосны — справочник по лесу

Справочник по лесу и лесной экономике простыми словами: строение сосны и всё, что из неё получают, лес в целом, отвод делянки, лесозаготовка, деревообработка, реализация древесины в России, лесовосстановление, план текстовой игры, каталог оборудования, словарь терминов и тест на знание каждого пункта.

**Автор:** Минигулов Александр Рафаильевич, 2026.

Работает как приложение на телефоне (PWA): ставится на главный экран, открывается без адресной строки и работает без интернета после первого запуска. Прогресс теста хранится на устройстве.

## Как опубликовать на GitHub Pages

1. Зарегистрируйтесь или войдите на github.com.
2. Создайте новый публичный репозиторий, например `drevo-sosny`.
3. На странице репозитория выберите загрузку файлов (Add file → Upload files), перетащите **все файлы из этой папки** и сохраните (Commit changes).
4. Откройте Settings → Pages. В разделе источника выберите ветку `main` и папку `/ (root)`, сохраните.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/drevo-sosny/`.

## Как установить на Google Pixel

1. Откройте адрес сайта в Chrome на телефоне.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. На главном экране появится иконка «Древо сосны». Приложение открывается на весь экран и работает офлайн.

## Если нужен APK-файл

Готовый сайт можно упаковать в Android-приложение через сервис PWABuilder (pwabuilder.com): вставить адрес сайта, выбрать Android и скачать пакет. Для установки APK вне Google Play телефон попросит разрешить установку из неизвестных источников.

## Состав

| Файл | Что внутри |
|---|---|
| `index.html` | Интерфейс: вкладки, древо, карточки, поиск |
| `glossary.js` | Словарь терминов |
| `pine.js` | Схема «Древо сосны» |
| `schemes1.js` | Схемы «Лес», «Отвод делянки», «Лесозаготовка» |
| `schemes2.js` | Схемы «Деревообработка», «Реализация», «Лесовосстановление», «Для игры» |
| `pine2.js` | Дополнения к «Древу сосны»: вредители и болезни, недостающие продукты, привязка карточек-ассетов |
| `tools.js` | Оборудование и инструменты |
| `quiz.js` | Тест |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | Установка на телефон и офлайн-режим |
| `*.webp` | Иллюстрации; `a_*.webp` — карточки видов сосны и сортиментов |

Данные хранятся в обычных JS-объектах: их удобно дополнять и позже использовать как базу для игры.

После изменения файлов увеличьте номер версии в `sw.js` (`drevo-sosny-v1` → `v2`), чтобы телефон подхватил обновление.

## Оговорка

Цифры в справочнике ориентировочные. Нормативы (ГОСТы, ставки платы, правила экспорта, правила заготовки и лесовосстановления) меняются — перед использованием в научной работе сверяйте их с действующими документами.
