# «Древо отраслей»: иллюстрированное учебное пособие

**Автор исходного справочника:** Минигулов Александр Рафаильевич.  
**Редакция пособия:** октябрь 2026 года.  
**Читать:** [Открыть электронное пособие](./index.html) · [Открыть приложение](../index.html).

## Концепция

Это **отдельная книга**, созданная на основе приложения «Древо отраслей». Её файлы хранятся только в каталоге `textbook/`; существующие файлы приложения не редактируются.

Пособие использует тексты, иерархию и назначенные картинки из исходных JavaScript-модулей и графических файлов, расположенных на уровень выше. Изменение содержания приложения при следующем обновлении будет отражаться в соответствующих карточках книги. Дополнительные учебные введения и задачи хранятся в собственном файле пособия и не внедряются в приложение.

## Содержание

- **Том I. Лесопромышленный комплекс:** ресурсы, производство, переработка, техника, рынок, УИС, перспективы, идеальный цикл, регионы.
- **Том II. Агропромышленный комплекс:** те же девять укрупнённых разделов, раскрытые применительно к АПК.
- **Том III. Межотраслевое взаимодействие:** ресурсы, обмен продукцией, совместная переработка, техника и энергия, экономика и риски, УИС, перспективы, идеальный цикл, регионы.
- **Том IV. Справочный аппарат:** словарь, оборудование, расчётные задачи, источники, а также дополнительные карточки, не входящие в ветви трёх первых томов.

У всех трёх отраслевых томов предусмотрено по девять глав. В каждом разделе исходная вложенность передаётся последовательно — от корня к подчинённым пунктам, с сохранением связей, названий и иллюстраций. Нумерация начинается с 1 внутри каждого тома.

## Как пользоваться

1. Откройте `textbook/index.html` через опубликованный сайт GitHub Pages или статический сервер, обслуживающий корень репозитория.
2. Выберите том или главу в оглавлении. Откройте карточку по ссылке, воспользуйтесь поиском, словарём или каталогом техники.
3. Для подготовки печатной версии откройте нужную главу или том и нажмите **«Печать / PDF»**. В окне печати браузера выберите **«Сохранить в PDF»**. При печати большого тома разумно сохранять главы по отдельности; графика требует времени на загрузку.
4. Чтобы открыть исходное интерактивное приложение, используйте кнопку в шапке.

## Ограничения и проверка

Изложение исходного справочника сохранено по смыслу; технические сведения и нормы могут изменяться. Числовые параметры и региональные карты имеют **ориентировочный учебный характер** и требуют проверки по первичным источникам с указанием года. Дополнительные теоретические комментарии и расчётные примеры подготовлены с помощью ИИ; примеры используют **синтетические данные**, а научное использование требует экспертной проверки.

В страницах учебного пособия используются исходные иллюстрации из корня репозитория — файлы изображений не дублируются. Поэтому для работы из отдельной копии необходимо сохранить папку `textbook/` *внутри* полного репозитория.

## Разработка и безопасность изменений

Изменения ограничиваются путями `textbook/*` в ветках репозитория. Никакие исходные `index.html`, `*.js`, `*.webp`, CSS, служебные файлы или манифесты самого приложения не меняются.
